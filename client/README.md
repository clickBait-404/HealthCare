# Health Frontend

The frontend for **Healthcare**, a full-stack healthcare appointment and patient follow-up management platform.

## 🚀 Overview

Healthcare provides role-based interfaces for:

- Patients
- Doctors
- Clinic Administrators

The frontend is built with React and Vite and communicates with the Express.js backend through REST APIs.

## 🛠️ Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React
- Date-fns
- React Router
- JavaScript
- REST API
